# Iras Course Planner 🎓🕶️

Iras Course Planner is a fast, intuitive Android application built to simplify university course advising and schedule building. Say goodbye to overlapping classes and manual timetable drawing.

## ✨ Key Features

* **⚡ Instant Conflict Detection:** Uses highly optimized bitmasking to detect schedule clashes in real-time as you add courses.
* **🔄 Seamless Section Swapping:** Easily swap between different lab, tutorial, and lecture sections to find the perfect fit.
* **📅 Visual Timetable Grid:** View your selected courses in a beautiful, easy-to-read weekly calendar layout.
* **💾 Save & Compare Plans:** Create multiple schedule drafts, save them locally, and compare which semester plan works best for you.
* **🖼️ High-Res Export:** Export your finalized weekly timetable as a polished, high-resolution image directly to your gallery.

## 🛠️ Tech Stack

* **Language:** [Kotlin](https://kotlinlang.org/)
* **UI Toolkit:** [Jetpack Compose](https://developer.android.com/jetpack/compose) (Material Design 3)
* **Architecture:** MVVM (Model-View-ViewModel)
* **Concurrency:** Kotlin Coroutines & Flows
* **Local Storage:** Room Database (SQLite)
